# Архитектура

Глоссарий предметной области — `CONTEXT.md`. Принятые решения и их причины — `docs/adr/` (0001–0012). Здесь — как устроен код.

## Поток данных

```
UI (src/ui/screens/*)
  └─ useData(): ds, costing, save, remove, reload      src/ui/DataContext.tsx
       ├─ Store.load() → Dataset (весь набор, одним разом)
       ├─ save/remove → Store.insert|update|remove, затем локальное обновление ds
       └─ computeCosting(ds, today) в useMemo → CostingResult   src/domain/costing/
Store = SheetsStore (таблица пользователя) | LocalStore (демо-режим и тесты UI)
SheetsStore → SheetsApi (src/google/sheetsApi.ts) → googleRequest (src/google/http.ts) → Sheets API v4
```

- Сессия (`SessionProvider`): `none` → экран входа, `demo` → `createDemoStore()` (localStorage, ключ `zk:demo`), `sheets` → store после привязки таблицы. Режим демо помнится в `zk:mode`.
- Данные грузятся целиком при входе и по `reload()`; фильтры и выборы на экранах — только показ, расчёт себестоимости всегда по всему `Dataset`.
- Экран «Себестоимость» пишет отчёт в лист `Себестоимость` через `store.writeReport` (лист очищается и пишется целиком).
- Вход Google: `src/google/auth.ts` (Google Identity Services, токен в памяти), `picker.ts` — выбор таблицы (с `setOrigin`, защита от окна без ответа), `driveApi.ts` — список таблиц, доступных приложению (`listAppSpreadsheets`), `scriptApi.ts` — Apps Script API. Подключение по ссылке — `openLinkedSpreadsheet` (`src/setup/connect.ts`): сначала прямой доступ, окно Google только при 403/404.
- Привязка таблицы (`src/setup/connect.ts`): `ensureSchema` приводит листы к схеме → `installScript` ставит скрипт курсов (`apps-script/Code.gs`, `appsscript.json`, импорт `?raw`) → привязка запоминается в localStorage `zk:binding:<email>`. Версия скрипта — хеш исходников (`SCRIPT_VERSION`); при расхождении с `_meta.scriptVersion` скрипт переставляется при следующем входе.
- Курсы в приложение приходят только через лист `Курсы`: скрипт таблицы ежедневно парсит страницу ВТБ и пишет строки `source=vtb`; руками — `source=manual` (экран «Курсы»).
- Импорт из старой таблицы (`src/import/`): `readLegacy` (6 видимых листов) → `mapLegacy` (чистая, колонки по заголовкам) → `applyImport` через текущий store.

## Границы модулей

| Модуль | Владеет | Не знает о |
|---|---|---|
| `src/domain/` | типы сущностей (`model.ts`), выбор курса, показатели позиции, движок себестоимости, подсказка коэффициента, валидация | вводе-выводе, React, Sheets |
| `src/store/` | схема листов (`schema.ts` — единственный источник правды о листах), сериализация строк, serial-даты, чтение/запись | UI, OAuth |
| `src/google/` | тонкие обёртки над `fetch`, повторы, обновление токена, типизированные ошибки | схеме листов |
| `src/setup/` | приведение таблицы к схеме, установка скрипта, привязка | экранам |
| `src/import/` | перенос из старой таблицы | UI-состоянию (получает `SheetsApi` и `Store` снаружи) |
| `src/ui/` | экраны, маршруты (HashRouter), сессия, общие компоненты | расчётам: только вызывает `domain` |
| `apps-script/` | скрипт таблицы: курсы ВТБ, меню «Закупки» | приложению; общий с ним только схема листов `Курсы`, `Настройки`, `Лог` |

- Серверной части нет. Один пользователь, одна таблица.
- `schema.ts` используют `store`, `setup` и `import`; добавили колонку — правите схему, `ensureSchema` дописывает её в существующие таблицы, не трогая чужие данные.
- Границу `Store` закрывает общий контрактный набор `tests/store/contract.ts`: обе реализации обязаны его проходить.

## Соглашения

- Имена в коде английские, тексты интерфейса и ошибок русские.
- Даты внутри — ISO `YYYY-MM-DD` (`ISODate`), дата-время — ISO 8601 в UTC; в serial-числа таблицы и обратно переводит только `store/schema.ts`.
- Деньги — `number`; округление только при показе (2 знака) и при записи отчёта; внутри расчёта не округляется. Формат показа — `src/ui/format.ts`, русская дата — `src/domain/format.ts: ruDate`.
- Валюты `'RUB' | 'CNY' | 'USD' | 'EUR'`; CNY в интерфейсе — «юань (RMB)».
- `id` записей — `newId(prefix)` из `src/domain/ids.ts`.
- Валидация (`src/domain/validation.ts`) возвращает `Record<поле, русский текст>`; пусто — всё верно.
- Удаление — через `ConfirmDelete`; допустимость удаления решают чистые `*DeleteBlock` рядом с экраном или в `src/ui/directories/`.
- Значения справочников (`Списки`) хранятся в записях строкой; переименование значения старые записи не меняет.
- Логика экрана — в `*Logic.ts` рядом с экраном (чистые функции, тестируются отдельно от React).
- Экран — `src/ui/screens/<имя>/<Имя>Screen.tsx`, default export; маршрут подключается в `src/ui/App.tsx`, пункт меню — в `src/ui/layout/menu.ts`.
- Общие компоненты и классы — `src/ui/components/` и `src/ui/styles.css`; экран не объявляет у себя общие классы (`tests/project.test.ts` это проверяет).
- ИИ, LLM и машинный перевод в коде запрещены; перевод названий делает формула `GOOGLETRANSLATE` в листе (ADR 0011).
- Кэш PWA — только оболочка приложения; запросы к Google не кэшируются (`vite.config.ts`).

## Расчёт себестоимости

Правила — в шапке `src/domain/costing/engine.ts`, решения — ADR 0006–0010.

- Единица расчёта — партия (`Batch`); неотгруженный остаток позиции — виртуальная партия `rest:<lineId>` (получает товар и комиссии, не доставку и таможню).
- Факт-затрата считается по курсу, зафиксированному в строке; план — по курсу даты расчёта.
- Затрата делится по привязке: поставщик в заказе — по стоимости в валюте, заказ — по стоимости в ₽ по курсу расчёта, поставка — контейнерная доставка: партии без CBM получают долю по весу от общего веса поставки, остаток — партиям с CBM по CBM (вес неизвестен — 1 CBM = 1000 кг); прочие затраты поставки — вес → стоимость, декларация — по таможенной стоимости, позиция — целиком на неё; внутри позиции доля делится между партиями по количеству.
- Прогноз таможни (`customsForecasts`) только для показа и в итоги не входит.
- Подсказка коэффициента — медиана AW позиций закрытых заказов (поставщик+тип доставки → тип → все), минимум три точки.

## Тесты

- `tests/**` зеркалит `src/**`; тесты скрипта таблицы — `apps-script/test/` (`Code.gs` грузится в node через `vm` с моками `SpreadsheetApp`/`UrlFetchApp`/`ScriptApp`, `harness.ts`).
- UI тестируется на `LocalStore`; `SheetsStore` и `setup` — на фейковом `SheetsApi` в памяти (`tests/store/sheetsStoreFake.ts`); сеть в тестах не ходит.
- Референс по реальным данным (`tests/import/reference.test.ts`) идёт только при наличии `fixtures/private/legacy.json`.
