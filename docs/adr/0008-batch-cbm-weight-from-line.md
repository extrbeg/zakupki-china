## Контекст

План (история «У части партий контейнера нет CBM») предполагал: если у партии нет CBM, доставка поставки делится по весу целиком, с предупреждением. Решение D01, принято при сборке движка.

## Решение

У партии без собственных CBM или веса движок берёт CBM и вес её позиции пропорционально количеству партии — так же, как это подставляет форма партии при создании. Только если CBM нет ни у партии, ни у позиции, доставка поставки делится по весу целиком с предупреждением со списком таких партий; нет и веса — по стоимости, тоже с предупреждением.

## Почему

Код показал, что исходное правило разрушает смысл самого R20: любая партия, созданная без CBM, роняла на вес весь контейнер, хотя у позиции CBM заведомо есть и достаточен для разумной оценки. Альтернативы:

- **Оставить как в плане** отвергнуто по причине выше.
- **Запретить сохранять партию без CBM** отвергнуто: спецификация прямо допускает партии без CBM, а значение у позиции обычно уже есть.
- **Подставлять только в форме, не в движке** отвергнуто: партии из импорта или старых записей без значения всё равно уронили бы контейнер.

## Последствия

- Подстановка существует в двух местах (форма партии и движок) с одной семантикой; при изменении одной нужно менять другую.
- Форма записывает значения в партию числами, поэтому позднейшая правка CBM позиции уже созданную партию не меняет; пересчитывается только партия без значений.
- Пропорциональный объём — оценка: если партия реально заняла иной объём, доля доставки неточна, и расчёт этого не покажет.
