# Закупки Китай

Приложение для учёта закупок в Китае: заказы с поставщиками и позициями, поставки (контейнер, авиа) из партий разных заказов, журнал затрат с курсом ВТБ на дату оплаты, справочники и себестоимость каждой позиции и партии с НДС — прогноз против факта.

Это PWA: ставится иконкой на Windows, Linux, Android и iPhone. Серверной части нет — данные лежат в вашей собственной Google-таблице, которую приложение само приводит к нужной схеме и в которую ставит скрипт ежедневной загрузки курсов. Все расчёты делает код, ИИ не используется.

## Запуск локально

Нужен Node.js 20 или новее.

```
npm install
npm run dev        # откроется на http://localhost:5173
npm run check      # проверка типов и тесты
npm run build      # сборка в dist/
```

### Демо-режим без Google

Без настройки Google ничего подключать не нужно: на экране входа нажмите «Попробовать без Google». Приложение работает на демо-данных, которые хранятся только в этом браузере.

### Вход через Google

Чтобы работать с настоящей таблицей, нужны три идентификатора из Google Cloud. Скопируйте `.env.example` в `.env` и впишите значения:

- `VITE_GOOGLE_CLIENT_ID` — OAuth Client ID;
- `VITE_GOOGLE_API_KEY` — ключ API (для выбора таблицы);
- `VITE_GOOGLE_APP_ID` — номер проекта Google Cloud.

`VITE_BASE_PATH` оставьте пустым для локального запуска. Файл `.env` в git не попадает.

Как получить эти значения, опубликовать приложение на GitHub Pages и поставить его на телефон или компьютер — пошагово в [docs/setup.md](docs/setup.md).

## Публикация

Workflow `.github/workflows/deploy.yml` при каждом push в `main` запускает `npm run check`, собирает приложение с переменными репозитория и публикует его на GitHub Pages.

## Данные

Коммерческие данные в репозиторий не коммитятся: выгрузки реальной таблицы кладите в `fixtures/private/` (папка в `.gitignore`).
