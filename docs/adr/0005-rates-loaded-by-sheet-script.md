## Контекст

Нужны ежедневные курсы ВТБ (USD, EUR, CNY; продажа, диапазон «до 10 000 единиц»). Курс ЦБ пользователю не нужен. Своего сервера нет, браузерное приложение закрыто большую часть суток. Официального API ВТБ нет, реальный ответ сайта разработчики не видели.

## Решение

Курсы каждый день загружает скрипт, привязанный к таблице пользователя, по расписанию около 10:00 по Москве. Он пишет одну строку на дату, валюту и источник; повторный запуск в тот же день дублей не создаёт. Приложение ставит скрипт при привязке, но расписание включается вручную из меню таблицы «Закупки» одним разрешением. Источник — сайт ВТБ; его адрес задаётся в настройках таблицы. Разбор терпимый к формату: сначала JSON, затем HTML-таблица. Проверка сертификата отключена. Кнопка «Проверить источник курсов» пишет в лог ответ и результат разбора. Ручной курс на дату можно ввести всегда, и он важнее автоматического.

## Почему

- **Загрузка курсов самим приложением** отвергнута: приложение не работает по расписанию, когда закрыто, а курс нужно сохранять каждый день, в том числе в дни, когда его не открывали.
- **Серверное расписание** отвергнуто вместе со своим сервером (0001).
- **Курс ЦБ** отвергнут пользователем: «мне курс ЦБ не интересен».
- **Строгий разбор под один формат страницы** отвергнут: формат неизвестен и может смениться; терпимый разбор плюс диагностика позволяют подогнать его по реальному ответу, не пересобирая приложение.
- **Проверка сертификата** оставлена выключенной: у сайта ВТБ сертификат российского удостоверяющего центра.
- **Полностью автоматическая установка расписания** невозможна: Google требует разрешения в самой таблице.

## Последствия

- Разбор не проверен на живом ответе сайта: после установки пользователь должен запустить проверку источника и прислать лист «Лог». Если ВТБ блокирует серверы Google, курсы вводятся только вручную.
- Без проверки сертификата ответ теоретически может быть подменён; защита — только то, что разбор принимает лишь правдоподобные курсы нужного диапазона.
- «Автоматически» на деле требует двух разовых шагов: включить Apps Script API и разрешить расписание; пока второй не сделан, курсов нет, и приложение показывает дату последнего автокурса.
- Код скрипта выполняется в аккаунте пользователя; обновляется при повторной привязке с новой версией приложения.
- Внутри валюта называется CNY, в интерфейсе «юань (RMB)».
