## Контекст

Пользователь подтвердил правило: пошлина по проценту кода ТН ВЭД позиции, НДС 22 % от таможенной стоимости плюс пошлины, сборы делятся между партиями декларации; себестоимость всегда с НДС. На каждого поставщика отдельная декларация, состав он задаёт сам. До оплаты пользователь хочет видеть прогноз таможенных платежей.

## Решение

Себестоимость всегда включает НДС. Пошлина и НДС попадают в себестоимость только из внесённых строк затрат, плановых или фактических. Прогноз таможни по декларации (пошлина из процента, НДС по ставке поставки, по умолчанию 22 %, ставка редактируется) только показывается: в себестоимость партий, плановые итоги и итоги заказа не входит. Состав деклараций задаёт пользователь; кнопка «По декларации на поставщика» лишь предлагает раскладку, которую можно править.

## Почему

- **Себестоимость без НДС** отвергнута пользователем: «всегда с ндс».
- **Автоматически включать прогноз таможни в себестоимость, пока нет факта** отвергнуто при ревью движка. Причина в материалах не записана; по смыслу правки: при внесении фактической затраты прогноз и факт дали бы две цифры одной пошлины, и понадобилось бы правило их замены.
- **Автоматическое окончательное разнесение партий по декларациям** отвергнуто пользователем: он указывает состав сам.

## Последствия

- Пока таможенная затрата не внесена, себестоимость занижена, а прогноз виден отдельно: легко не заметить разницу и принять заниженное число за итог.
- Чтобы план по таможне попал в итоги, пользователь вносит плановую строку затрат вручную.
- Ставка НДС хранится в каждой поставке отдельно: изменение ставки не пересчитывает старые поставки, но и не защищает от забытого обновления в новых.
- Партия без декларации не получает таможенных затрат, показывается предупреждение (0007).
