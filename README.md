# Закупки Китай

Приложение для учёта закупок в Китае: заказы с поставщиками и товарами, сравнение цен поставщиков, поставки (контейнер, авиа) из партий разных заказов, журнал затрат с курсом ВТБ на дату оплаты, справочники и себестоимость каждого товара с НДС — прогноз против факта.

**Открыть приложение:** https://extrbeg.github.io/zakupki-china/

Данные хранятся не в приложении, а в вашей собственной Google-таблице: приложение само создаёт в ней нужные листы и ставит скрипт ежедневной загрузки курсов. Все расчёты делает код, ИИ не используется.

## Установка на телефон и компьютер

Приложение ставится прямо из браузера, как обычная программа: со своей иконкой и в отдельном окне. Магазины приложений (Google Play, App Store) не нужны. Можно и не ставить — просто открывать ссылку в браузере.

### Android

1. Откройте ссылку на приложение в **Chrome**.
2. Нажмите меню **⋮** (три точки справа вверху) → **«Установить приложение»**. На некоторых телефонах пункт называется **«Добавить на главный экран»**.
3. Подтвердите **«Установить»**.

Иконка «Закупки» появится на главном экране и в списке приложений.

- **Samsung Internet:** меню **≡** → **«Добавить страницу на»** → **«Главный экран»**.
- **Яндекс Браузер** и другие могут добавить только ярлык-закладку, а не приложение — лучше ставить через Chrome.

### iPhone и iPad

1. Откройте ссылку на приложение в **Safari**.
2. Нажмите кнопку **«Поделиться»** — квадрат со стрелкой вверх (внизу экрана на iPhone, вверху на iPad).
3. Пролистайте список вниз и выберите **«На экран "Домой"»**.
4. Нажмите **«Добавить»**.

Иконка появится на экране «Домой» — запускайте приложение с неё.

- На iOS 16.4 и новее так же можно установить из Chrome: кнопка «Поделиться» в адресной строке → «На экран "Домой"».
- Если вход через Google из иконки не открывается или зацикливается, один раз войдите через обычную вкладку Safari, затем возвращайтесь к иконке.

### Windows

1. Откройте ссылку в **Chrome** или **Edge**.
2. Справа в адресной строке нажмите значок установки (монитор со стрелкой) → **«Установить»**.
   Если значка нет:
   - **Chrome:** меню **⋮** → **«Трансляция, сохранение и общий доступ»** → **«Установить страницу как приложение»**;
   - **Edge:** меню **…** → **«Приложения»** → **«Установить этот сайт как приложение»**.

Приложение появится в меню «Пуск»; его можно закрепить на панели задач.

### Linux

Так же, как на Windows, в **Chrome, Chromium, Edge** или **Brave**: значок установки в адресной строке или меню **⋮** → **«Установить Закупки Китай»**. Иконка появится в меню приложений.

**Firefox** на компьютере устанавливать приложения не умеет — откройте ссылку в одном из браузеров выше или пользуйтесь обычной вкладкой.

### macOS

- **Chrome** или **Edge:** значок установки в адресной строке → **«Установить»**.
- **Safari** (macOS 14 Sonoma и новее): меню **«Файл»** → **«Добавить в Dock»**.

## Первый вход

1. Откройте приложение и нажмите **«Войти через Google»**.
   Войти может только тот, чья почта добавлена владельцем приложения в список пользователей. Если Google пишет «Доступ заблокирован» — попросите владельца добавить вашу почту.
2. Google покажет предупреждение **«Google не проверила это приложение»**. Это нормально для частного приложения: нажмите **«Дополнительные настройки»** → **«Перейти на страницу… (небезопасно)»** и **оставьте все галочки доступа включёнными**.
3. Подключите таблицу:
   - **«Создать новую таблицу»** — приложение создаст её в вашем Google Диске;
   - или вставьте **ссылку на свою таблицу** в поле «Ссылка на таблицу» — откроется окно Google с этим файлом, нажмите **«Выбрать»**.

   Приложение получает доступ только к таблицам, которые вы сами создали через него или выбрали — не ко всему Google Диску.
4. **Ежедневные курсы ВТБ** включаются один раз в самой таблице: откройте её, в меню **«Закупки»** выберите **«Включить ежедневные курсы»** и разрешите доступ. Если меню «Закупки» не видно — обновите страницу таблицы.

Перенести данные из старой таблицы можно в **«Настройки» → «Импорт из старой таблицы»**.

Попробовать приложение без Google можно кнопкой **«Попробовать без Google»** — демо-данные хранятся только в этом браузере.

## Обновления

Приложение обновляется само. Если новая версия вышла, пока приложение открыто, появится плашка **«Доступна новая версия — Обновить»**. После обновления один раз показывается, что изменилось. Номер версии — внизу меню, вся история — в пункте **«Что нового»**.

Ваши данные от обновлений не зависят: они лежат в вашей Google-таблице.

## Частые вопросы

| Что происходит | Что делать |
|---|---|
| После обновления страницы снова просит войти | Так задумано: доступ к таблице хранится только в открытой вкладке. Нажмите «Войти через Google» — таблица откроется сразу. |
| Сайт не открывается: «Не удаётся найти сайт» | Скорее всего, мешает DNS вашей сети или провайдера. Поставьте в настройках сети DNS 1.1.1.1 или 8.8.8.8, либо откройте с мобильного интернета. |
| «Доступ заблокирован» при входе | Вашей почты нет в списке пользователей — обратитесь к владельцу приложения. |
| Нет меню «Закупки» в таблице | Обновите страницу таблицы; если не помогло — в приложении «Настройки» → переустановить скрипт. |
| Курсы не загружаются | В таблице «Закупки» → «Проверить источник курсов» и пришлите содержимое листа «Лог». Пока курсы можно вносить вручную на экране «Курсы». |

## Для разработчика

Нужен Node.js 20 или новее.

```
npm install
npm run dev        # http://localhost:5173
npm run check      # проверка типов и тесты
npm run build      # сборка в dist/
```

Для входа через Google локально скопируйте `.env.example` в `.env` и впишите `VITE_GOOGLE_CLIENT_ID`, `VITE_GOOGLE_API_KEY`, `VITE_GOOGLE_APP_ID`; `VITE_BASE_PATH` оставьте пустым. Файл `.env` в git не попадает.

- Настройка Google Cloud и публикация на GitHub Pages — пошагово в [docs/setup.md](docs/setup.md).
- Устройство проекта — [docs/architecture.md](docs/architecture.md), решения — [docs/adr/](docs/adr/), словарь — [CONTEXT.md](CONTEXT.md), история версий — [CHANGELOG.md](CHANGELOG.md).
- Публикация: workflow `.github/workflows/deploy.yml` при push в `main` запускает проверку, собирает приложение с переменными репозитория и публикует его на GitHub Pages.
- Коммерческие данные в репозиторий не коммитятся: выгрузки реальной таблицы — в `fixtures/private/` (папка в `.gitignore`).
